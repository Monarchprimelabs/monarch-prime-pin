# StoreKit test configuration

`Products.storekit` holds the four 2.0 products for testing purchases in
Xcode without App Store Connect: the legacy $9.99 Lifetime Pro, Lifetime
Premium ($79.99), and the Premium subscription group with Monthly ($4.99) and
Annual ($39.99, 1-week free trial for new subscribers).

The iOS project is generated by `expo prebuild`, so the file lives here
rather than in `ios/`. To use it on a Mac: `npx expo prebuild -p ios`, open
`ios/*.xcworkspace`, add `storekit/Products.storekit` to the project, then
Product > Scheme > Edit Scheme > Run > Options > StoreKit Configuration.
It never ships in a build.
